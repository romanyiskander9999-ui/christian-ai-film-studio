# استوديو الينبوع السينمائي

استوديو عربي لإنشاء سيناريوهات ومشاهد للأفلام والقصص المسيحية، مع جعل النماذج المفتوحة المصدر والخدمات المجانية هي المسار الافتراضي.

## 1) توليد السيناريو مجانًا عبر Ollama
1. ثبّت Ollama على جهاز أو خادم تملكه: https://ollama.com/
2. نزّل نموذجًا مناسبًا مثل `qwen2.5:7b` عبر `ollama pull qwen2.5:7b`.
3. شغّل خادم Ollama، واجعل عنوانه متاحًا لخادم تطبيق Next.js. عند النشر على Vercel لا تستخدم `localhost`؛ يلزم عنوان خادم يمكن الوصول إليه بأمان.
4. أضف `OLLAMA_API_URL` و`OLLAMA_MODEL` إلى متغيرات البيئة.
5. لا يستدعي التطبيق OpenAI أو أي نموذج نصي مدفوع. إذا لم يكن Ollama مضبوطًا، يعرض التطبيق تعليمات بدلًا من الاتصال بخدمة مدفوعة.

## 2) إنتاج الفيديو المجاني
- Dreamina وPixVerse: انسخ وصف المشهد وافتح الموقع بنفسك. الرصيد المجاني يختلف حسب الحساب والبلد وقد يتغير.
- نزّل المقطع ثم ارفعه إلى المشهد لمعاينته.
- لا توجد طلبات مدفوعة تلقائية ولا تكامل Runway مفعل.

## 3) نموذج الفيديو المفتوح المصدر: Wan 2.2 عبر ComfyUI
1. ثبّت ComfyUI وشغّل Workflow متوافقًا مع Wan 2.2.
2. صدّر الـWorkflow بصيغة API JSON.
3. اجعل خادم ComfyUI متاحًا لتطبيق Next.js عبر شبكة آمنة.
4. أضف:
   - `COMFYUI_API_URL`
   - `COMFYUI_WORKFLOW_JSON`: نص JSON الكامل بصيغة API.
   - `COMFYUI_PROMPT_NODE_ID`: رقم عقدة النص الإيجابي.
   - `COMFYUI_PROMPT_INPUT`: اسم مدخل النص، غالبًا `text`.
5. قد تختلف العقد والمدخلات حسب Workflow المستخدم.

المستودعات: https://github.com/Wan-Video/Wan2.2 و https://github.com/comfyanonymous/ComfyUI

## التشغيل
1. Node.js 20+
2. `npm install`
3. أضف متغيرات Ollama المحلية عند الحاجة.
4. `npm run dev`

## التكلفة والخصوصية
- لا يرسل التطبيق طلبات إلى خدمات فيديو مدفوعة.
- لا يستدعي التطبيق OpenAI أو Runway.
- النماذج المفتوحة المصدر لا تفرض رسومًا لكل طلب، لكن الجهاز أو خادم GPU والكهرباء والاستضافة قد تكون لها تكلفة.
- أرصدة Dreamina وPixVerse المجانية ليست مضمونة أو ثابتة، وواجهتهما الخارجية ليست API مجانيًا مضمونًا.
- ملفات الفيديو المرفوعة للمعاينة محلية في جلسة المتصفح الحالية ولا تُرفع تلقائيًا إلى تخزين سحابي.
