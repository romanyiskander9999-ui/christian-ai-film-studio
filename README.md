# استوديو الينبوع السينمائي

نسخة عربية لإنشاء سيناريوهات ومشاهد للأفلام والقصص المسيحية.

## مسار إنتاج الفيديو المجاني (الافتراضي)
- Dreamina وPixVerse: ينسخ المستخدم وصف المشهد ويفتح الموقع بنفسه. الرصيد المجاني وشروطه يحددهما كل مزود وقد يتغيران حسب البلد والحساب.
- بعد تنزيل المقطع من الموقع، يمكن رفعه إلى المشهد داخل الاستوديو لمعاينته.
- لا يوجد إرسال تلقائي إلى Runway أو أي خدمة فيديو مدفوعة. مسارات Runway البرمجية معطلة عمدًا وتعيد HTTP 410.

## نموذج مفتوح المصدر: Wan 2.2 عبر ComfyUI
يمكن تشغيل Wan 2.2 على جهاز GPU أو خادم GPU خاص. هذا يتجنب رسوم المزود لكل فيديو، لكنه لا يعني أن موارد GPU أو الكهرباء أو الاستضافة مجانية.

لإعداد التكامل:
1. ثبّت ComfyUI وشغّل Workflow متوافقًا مع Wan 2.2.
2. صدّر الـWorkflow بصيغة API JSON من ComfyUI.
3. اجعل خادم ComfyUI متاحًا لتطبيق Next.js عبر شبكة آمنة.
4. أضف في بيئة الخادم:
   - `COMFYUI_API_URL`: عنوان خادم ComfyUI.
   - `COMFYUI_WORKFLOW_JSON`: نص JSON الكامل بصيغة API.
   - `COMFYUI_PROMPT_NODE_ID`: رقم عقدة النص الإيجابي في الـWorkflow.
   - `COMFYUI_PROMPT_INPUT`: اسم مدخل النص، غالبًا `text`.
5. لا تضع بيانات دخول الخادم في الواجهة الأمامية أو في GitHub.

الـWorkflow يجب أن يكون مهيأً مسبقًا لنموذج Wan 2.2 وأن يحتوي على عقدة prompt قابلة للتعديل. قد تختلف أسماء العقد والمدخلات حسب الـWorkflow.

## التشغيل
1. Node.js 20+
2. `npm install`
3. أضف `OPENAI_API_KEY` لإنشاء السيناريوهات (هذه خدمة منفصلة عن توليد الفيديو).
4. `npm run dev`

## حدود مهمة
- أرصدة Dreamina وPixVerse المجانية ليست مضمونة أو ثابتة، ولا يعني ذلك توفر API مجاني.
- ملفات الفيديو المرفوعة تُعاين محليًا في جلسة المتصفح الحالية؛ لا تُرفع تلقائيًا إلى تخزين سحابي.
- خادم GPU الخاص قد يترتب عليه تكلفة استضافة أو كهرباء.
- لا توجد خدمة فيديو مدفوعة مفعّلة افتراضيًا.
