# استوديو الينبوع السينمائي

نسخة أولية لبناء سيناريو عربي ولوحة مشاهد للأفلام والقصص المسيحية.

## الموجود في الإصدار 0.1
- واجهة عربية RTL متجاوبة.
- إدخال فكرة القصة والطابع البصري والمدة والجمهور والمرجع.
- توليد سيناريو منظم إلى شخصيات ومشاهد وحوار وتعليق صوتي وأوصاف بصرية.
- ملاحظات توثيق لتجنب عرض المعالجة الدرامية على أنها نص تاريخي موثق.
- دليل بصري موحد للشخصيات والحقبة والألوان والاستمرارية.
- أوصاف منفصلة لتوليد الصور والفيديو والمؤثرات الصوتية لكل مشهد.
- ربط اختياري بخدمة Runway لإنشاء مقاطع فيديو قصيرة لكل مشهد ومتابعة حالة المهام.

## التشغيل محليًا
1. ثبّت Node.js 20 أو أحدث.
2. نفّذ `npm install`.
3. انسخ `.env.example` إلى `.env.local`.
4. أضف مفتاح OpenAI إلى `OPENAI_API_KEY`.
5. نفّذ `npm run dev` ثم افتح http://localhost:3000.

## النشر
استورد هذا المستودع في Vercel، ثم أضف `OPENAI_API_KEY` و`OPENAI_MODEL`. ولتفعيل توليد الفيديو أضف `RUNWAYML_API_SECRET`، ويمكن اختيار النموذج عبر `RUNWAY_VIDEO_MODEL` (الافتراضي `gen4.5`).

## مهم
توليد الفيديو يعمل كمهمة خارجية غير متزامنة لكل مشهد، ويحتاج مفتاح Runway ورصيدًا مدفوعًا. المقاطع الناتجة تُعرض داخل المشهد عند اكتمالها. دمج جميع المقاطع والصوت في فيلم MP4 واحد ما زال مرحلة لاحقة. لا تضع أي مفتاح API في ملفات GitHub أو الواجهة الأمامية.
