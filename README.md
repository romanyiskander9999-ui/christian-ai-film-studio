# استوديو الينبوع السينمائي

## تجهيز Windows
1. نزّل المستودع ZIP وفك الضغط.
2. شغّل `تجهيز_الاستوديو_المجاني.ps1` من PowerShell:
   `powershell -ExecutionPolicy Bypass -File .\تجهيز_الاستوديو_المجاني.ps1`
3. يثبت Ollama وNode.js عبر winget، وينزّل نموذج `qwen2.5:1.5b` الأخف على الأجهزة القديمة، ويثبت مكتبات المشروع.
4. شغّل `تشغيل_الاستوديو_محليًا.bat` وافتح http://localhost:3000.

## Wan 2.2 الاختياري
- شغّل `تجهيز_ComfyUI_Wan22.ps1` لتثبيت ComfyUI واعتماديات Python.
- ثبّت PyTorch المطابق لبطاقة الرسوميات من https://pytorch.org/get-started/locally/
- نزّل أوزان Wan 2.2 من https://huggingface.co/Wan-AI (كبيرة جدًا؛ لا تُنزّل تلقائيًا).
- شغّل `تشغيل_ComfyUI.bat`، وأنشئ Workflow متوافقًا وصدّره بصيغة API JSON.

## المتغيرات
```
OLLAMA_API_URL=http://127.0.0.1:11434
OLLAMA_MODEL=qwen2.5:1.5b
COMFYUI_API_URL=http://127.0.0.1:8188
COMFYUI_WORKFLOW_JSON=
COMFYUI_PROMPT_NODE_ID=
COMFYUI_PROMPT_INPUT=text
```

## حدود مهمة
- Vercel لا يستطيع الوصول إلى localhost على جهازك. لتشغيل Ollama وComfyUI على جهازك يجب تشغيل نسخة التطبيق محليًا.
- لا توجد مفاتيح OpenAI أو Runway مطلوبة، ولا طلبات فيديو مدفوعة.
- تشغيل النماذج محليًا بلا رسوم API، لكنه يحتاج موارد GPU وكهرباء ومساحة تخزين.
- Dreamina وPixVerse يقدمان أرصدة مجانية وفق شروط كل حساب، وليست API مجانية مضمونة.


## توليد الفيديو السحابي من داخل الموقع
- أُضيفت مساحة عامة لتجربة Wan 2.2 Remix SFW على Hugging Face داخل لوحة كل مشهد: https://huggingface.co/spaces/mastaP/wan22-remix-sfw-t2v
- انسخ وصف المشهد من الاستوديو ثم الصقه في واجهة المساحة المضمّنة، وابدأ التوليد من هناك.
- هذه تجربة مجانية عبر ZeroGPU بحصة محدودة وانتظار محتمل؛ توضح وثائق Hugging Face أن الحساب المجاني لديه 5 دقائق GPU يوميًا، وقد تتغير الإتاحة والقيود.
- المساحة العامة ليست جزءًا من خادم Vercel ولا نتحكم في استمرارها أو طوابيرها. لا يتم تشغيل أي خدمة مدفوعة تلقائيًا.
- مرجع الحصة وواجهة API: https://huggingface.co/docs/hub/spaces-zerogpu و https://huggingface.co/docs/hub/spaces-api-endpoints


## إرسال مشهد مباشرة إلى Wan 2.2 السحابي
- من بطاقة المشهد اضغط «إنتاج الفيديو مباشرة مجانًا».
- يرسل الموقع وصف المشهد إلى واجهة Gradio العامة لمساحة `mastaP/wan22-remix-sfw-t2v` على Hugging Face عبر خادم Next.js، ثم يعرض رقم المهمة وحالتها.
- اضغط «تحديث حالة التوليد» لمتابعة المهمة. عند رجوع رابط الفيديو يظهر مشغل المقطع داخل المشهد.
- لا يلزم مفتاح API ولا تُفعّل أي خدمة مدفوعة في هذا المسار. الحصة المجانية محدودة (5 دقائق GPU يوميًا لحساب Hugging Face المجاني بحسب الوثائق الحالية)، وقد توجد طوابير انتظار أو توقف مؤقت.
- تُرسل أوصاف المشاهد إلى بنية Hugging Face لمعالجتها. لا تضع معلومات خاصة أو حساسة في الوصف.
- تنبيه حقوقي: صفحة مساحة Wan Remix تصفها بأنها عرض تقني شخصي غير تجاري، وتذكر أن ترخيص أوزان Remix وحقوق المخرجات غير محسومة؛ راجع شروط المساحة قبل أي استخدام تجاري.
- API موثق في: https://huggingface.co/docs/hub/en/spaces-api-endpoints

## توصيل نسخة Vercel المنشورة بـ Ollama على جهازك
- توليد السيناريو أصبح يتصل من المتصفح مباشرة بـ Ollama؛ لا يلزم إضافة OLLAMA_API_URL في إعدادات Vercel.
- في الاستوديو استخدم العنوان `http://127.0.0.1:11434` والنموذج `qwen2.5:1.5b` ثم اضغط «اختبار اتصال Ollama».
- لأن الموقع يعمل من نطاق Vercel، اسمح لهذا النطاق في Ollama. أغلق Ollama أولًا، ثم افتح PowerShell ونفّذ:
  ```powershell
  [Environment]::SetEnvironmentVariable("OLLAMA_ORIGINS","https://christian-ai-film-studio.vercel.app","User")
  ```
  افتح Ollama مجددًا من قائمة Start. إذا كنت تستخدم نطاق نشر مختلفًا، استبدل النطاق بالقيمة التي يظهر بها الموقع في شريط العنوان.
- قد يطلب Chrome أو Edge إذن الوصول إلى الأجهزة على الشبكة المحلية؛ وافق إذا ظهر الطلب. لا تستخدم `OLLAMA_ORIGINS=*` ولا تفتح المنفذ 11434 للإنترنت.
- إذا منع المتصفح الاتصال بسبب CORS أو سياسة الوصول للشبكة المحلية، استخدم نسخة المشروع المحلية عبر `تشغيل_الاستوديو_محليًا.bat`.
- النموذج 1.5B أخف من 7B ومناسب أكثر للذاكرة المحدودة، لكنه قد يكون أبطأ وأقل دقة في السيناريوهات الطويلة. لا توجد خدمة مدفوعة في هذا المسار.
