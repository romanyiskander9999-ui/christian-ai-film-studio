# استوديو الينبوع السينمائي

نسخة أولية لبناء سيناريو عربي ولوحة مشاهد للأفلام والقصص المسيحية.

## الموجود في الإصدار 0.1
- واجهة عربية RTL متجاوبة.
- إدخال فكرة القصة والطابع البصري والمدة والجمهور والمرجع.
- توليد سيناريو منظم إلى شخصيات ومشاهد وحوار وتعليق صوتي وأوصاف بصرية.
- ملاحظات توثيق لتجنب عرض المعالجة الدرامية على أنها نص تاريخي موثق.

## التشغيل محليًا
1. ثبّت Node.js 20 أو أحدث.
2. نفّذ `npm install`.
3. انسخ `.env.example` إلى `.env.local`.
4. أضف مفتاح OpenAI إلى `OPENAI_API_KEY`.
5. نفّذ `npm run dev` ثم افتح http://localhost:3000.

## النشر
استورد هذا المستودع في Vercel، ثم أضف متغير البيئة `OPENAI_API_KEY` و `OPENAI_MODEL` قبل النشر.

## مهم
هذا الإصدار يُنشئ السيناريو ولوحة المشاهد فقط، ولا يصدر MP4 بعد. المرحلة التالية ربط خدمة توليد الفيديو والصور والصوت ثم تركيب المشاهد. لا تضع أي مفتاح API في ملفات GitHub أو الواجهة الأمامية.
